# Excel导入SQLite数据库功能示意图

## 标签页内部结构

```
+-----------------------------------------------------------------------------+
|                            导入到SQLite                                    |
+-----------------------------------------------------------------------------+
|                                                                             |
| +-----------------------------------------+                                 |
| |  SQLite数据库: [文件路径]                |                                 |
| | [选择数据库] [新建数据库]               |                                 |
| +-----------------------------------------+                                 |
|                                                                             |
| +-----------------------------------------+                                 |
| |  字段映射与类型设置区域                  |                                 |
| +-----------------------------------------+                                 |
| | +-------------------------------------+ |                                 |
| | | 原始列    | 目标字段 | 数据类型 | 导入 | |                                 |
```

## 各区域功能说明

1. **数据库选择区域**（最上方）
   - 用于选择或新建SQLite数据库文件
   - 显示当前选择的数据库文件路径
2. **字段映射与类型设置区域**（中间）
   - 显示Excel列与数据库字段的映射关系
   - 可选择是否导入特定列
   - 为每个字段设置SQLite数据类型（TEXT、INTEGER、REAL、BLOB）
   - 支持设置主键、唯一约束和非空约束
3. **操作按钮区域**
   - 开始导入：执行导入操作
   - 取消：取消当前操作
4. **导入进度区域**
   - 显示导入进度条
   - 显示当前导入状态和统计信息

## 数据流程

1. 用户选择Excel文件和工作表
2. 用户选择或新建SQLite数据库
3. 系统读取Excel数据并显示列信息
4. 用户设置字段映射和数据类型
5. 用户配置导入选项
6. 用户点击开始导入按钮
7. 系统执行导入操作并显示进度
8. 导入完成后显示结果统计

## 界面特点

- 布局清晰，功能区域划分明确
- 操作流程直观，符合用户习惯
- 提供实时进度反馈
- 支持多种导入选项，满足不同需求
