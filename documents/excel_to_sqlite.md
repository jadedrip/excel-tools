# Excel导入SQLite数据库功能说明

## 功能概述

Excel导入SQLite数据库功能允许用户将Excel文件中的数据导入到SQLite数据库中，支持字段映射、类型设置等功能。

## 界面描述

### 标签页布局

在Excel处理工具的主界面中，添加一个新的标签页"导入到SQLite"，包含以下功能区域：

#### 1. 数据库选择区域（最上方）
- **SQLite数据库**：显示当前选择的SQLite数据库文件路径
- **选择数据库**按钮：用于选择现有的SQLite数据库文件
- **新建数据库**按钮：用于创建新的SQLite数据库文件

#### 2. 字段映射与类型设置区域（中间）
- **字段映射表格**：显示Excel列与数据库字段的映射关系，包含以下列：
  - 原始列名
  - 目标字段名
  - 数据类型（下拉选择）
  - 是否导入（复选框）
- **自动映射**按钮：根据列名自动匹配Excel列与数据库字段
- **清空映射**按钮：清空所有映射关系

#### 3. 操作按钮区域
- **预览数据**按钮：预览Excel数据和映射结果
- **开始导入**按钮：开始执行导入操作
- **取消**按钮：取消当前操作

#### 4. 导入进度区域
- **进度条**：显示导入进度
- **状态信息**：显示当前导入状态和统计信息

## 使用流程

1. **在主界面选择Excel文件**：在标签页外的主界面上点击"打开Excel文件"按钮选择要导入的Excel文件
2. **在主界面选择工作表**：在标签页外的主界面上从"Sheet选择"下拉框中选择要导入的工作表
3. **选择或新建SQLite数据库**：在"导入到SQLite"标签页中点击"选择数据库"或"新建数据库"按钮
4. **字段映射与类型设置**：
   - 点击"自动映射"按钮自动匹配Excel列与数据库字段
   - 或手动调整映射关系
   - 为每个字段设置数据类型
   - 设置主键、唯一约束和非空约束
5. **预览数据**：点击"预览数据"按钮查看导入预览
6. **开始导入**：点击"开始导入"按钮执行导入操作
7. **查看结果**：导入完成后查看导入结果和统计信息

## 功能特点

### 1. 智能字段映射
- 根据列名自动匹配Excel列与数据库字段
- 支持手动调整映射关系
- 支持忽略不需要导入的列

### 2. 灵活的数据类型设置
- 支持SQLite的所有数据类型
- 自动根据Excel数据类型推荐合适的SQLite数据类型
- 支持手动调整数据类型

### 3. 详细的导入进度和统计
- 实时显示导入进度
- 显示导入成功和失败的记录数
- 显示导入过程中的错误信息

### 4. 错误处理
- 自动处理数据类型不匹配的情况
- 提供详细的错误信息
- 支持跳过错误记录继续导入

## 技术实现

### 数据读取
- 使用pandas库读取Excel文件
- 支持.xlsx和.xls格式
- 支持读取指定工作表的数据

### 数据库操作
- 使用sqlite3库操作SQLite数据库
- 支持创建新表和使用现有表
- 支持事务处理，确保数据一致性

### 字段映射
- 基于列名的自动匹配算法
- 支持自定义映射关系
- 支持字段类型转换

### 导入优化
- 批量导入机制，提高导入速度
- 内存使用优化，支持处理大型Excel文件
- 错误处理机制，确保导入过程的稳定性

## 应用场景

### 1. 数据备份
- 将Excel数据备份到SQLite数据库中
- 提供更可靠的数据存储方式

### 2. 数据迁移
- 将Excel数据迁移到SQLite数据库中
- 为应用程序提供数据支持

### 3. 数据分析
- 将Excel数据导入到SQLite数据库中
- 使用SQL语句进行更复杂的数据分析

### 4. 数据集成
- 将多个Excel文件的数据集成到一个SQLite数据库中
- 实现数据的集中管理

## 注意事项

1. **Excel文件格式**：支持.xlsx和.xls格式的Excel文件
2. **数据类型**：注意Excel数据类型与SQLite数据类型的对应关系
3. **字段长度**：注意SQLite字段长度限制
4. **主键设置**：确保主键字段的值唯一
5. **导入性能**：对于大型Excel文件，建议适当调整批量大小
6. **错误处理**：导入过程中可能会出现数据类型不匹配等错误，需要适当处理

## 示例操作

### 示例1：导入新数据到新表
1. 选择Excel文件和工作表
2. 选择或新建SQLite数据库
3. 输入新表名
4. 自动映射字段
5. 调整数据类型和约束
6. 选择"如果表已存在"为"覆盖表"
7. 点击"开始导入"

### 示例2：追加数据到现有表
1. 选择Excel文件和工作表
2. 选择现有SQLite数据库
3. 输入现有表名
4. 自动映射字段
5. 调整数据类型和约束
6. 选择"如果表已存在"为"追加数据"
7. 点击"开始导入"

### 示例3：只导入部分列
1. 选择Excel文件和工作表
2. 选择SQLite数据库
3. 输入表名
4. 手动调整映射关系，取消不需要导入的列
5. 点击"开始导入"

## 常见问题

### 1. 导入失败
- 检查Excel文件格式是否正确
- 检查SQLite数据库文件权限
- 检查字段映射是否正确
- 检查数据类型是否匹配

### 2. 导入速度慢
- 调整批量大小
- 减少需要导入的列数
- 确保Excel文件和SQLite数据库在同一磁盘上

### 3. 数据类型错误
- 检查Excel数据格式
- 手动调整数据类型设置
- 考虑使用TEXT类型兼容所有数据

### 4. 主键冲突
- 确保主键字段的值唯一
- 选择合适的"如果表已存在"处理方式

## 总结

Excel导入SQLite数据库功能提供了一种便捷的方式将Excel数据转换为SQLite数据库格式，支持智能字段映射、灵活的数据类型设置和强大的导入选项，适用于数据备份、迁移、分析和集成等多种场景。通过直观的用户界面，用户可以轻松完成Excel数据到SQLite数据库的导入操作，提高数据处理效率。
